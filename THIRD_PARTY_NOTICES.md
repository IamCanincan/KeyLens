# Third-party notices

The WebUI in `module/webroot/index.html` contains a minified, tree-shaken
bundle built from the following packages. The bundle is inlined so the module
does not fetch anything at runtime.

| Package | Version | License |
| --- | --- | --- |
| [@material/web](https://github.com/material-components/material-web) | 2.5.0 | Apache-2.0 |
| [lit](https://github.com/lit/lit) | 3.3.3 | BSD-3-Clause |
| [tslib](https://github.com/Microsoft/tslib) | 2.x | 0BSD |

The Material Symbols icon font is **not** included; the interface uses its own
inline SVG icons. The bundle is generated by `tools/mwc-build/build.mjs`.
